## 1차 검수에서 통과로 확인된 주요 항목

- 기능 완결성 F1: ①②③ 전경, ④ 토글(localStorage·matchMedia 코드 확인), ⑤ 대비 테스트
- 토큰 일관성 V1: theme.ts 값이 앱 theme.css 와 일치. 스윕 경계 노을 주황 → 인디고 치환
- 카드 命门 S4: 라이트/다크 캡처 레이아웃 픽셀 일치, 필터 반전 없음, 전환 1회, 모션 블러는 빠른 구간만, 바늘 s+46 고정
- 데이터 D1: 실명 → 가상 이름 대체 확인
- 음향 A2·A3·A4: 큐 정점 오차 ≤1f, BGM 드롭이 S4 컷(301f), riser→impact→sparkle
- A8: 두 버전 영상 프레임 732f framemd5 동일
- R4: 화면 전체 충격 0회 · Q8·S1 의도적 예외(§5) 타당
